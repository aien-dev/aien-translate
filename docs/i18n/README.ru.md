> Эта страница была автоматически переведена с помощью aien-translate, работающего на собственной модели AIEN. [Английская версия](../../README.md) является оригиналом.

Переведите свой сайт на 31 язык с помощью собственной модели ИИ. Без ключа API, без облачного сервиса, и текст посетителей никогда не покидает ваш сервер.

aien-translate — это сервер перевода для [translate.js](https://github.com/xnx3/translate). Он переводит с использованием собственного рантайма вывода AIEN. Также работает с любым сервером, предлагающим API-интерфейс стиля OpenAI.

## Переведите свой сайт за 3 шага

**1. Запустите сервер.** Вам нужен Rust и работающий сервер модели (AIEN's `aien-serve-http` или любой сервер с API-интерфейсом стиля OpenAI).

```
git clone https://github.com/aien-dev/aien-translate
cd aien-translate
cargo build --release
./target/release/aien-translate --listen 0.0.0.0:18097 --engine http://127.0.0.1:18091
```

**2. Добавьте translate.js на свою страницу.** Скачайте `translate.js` из [репозитория](https://github.com/xnx3/translate) и разместите его вместе со своим сайтом. Затем добавьте эти строки перед `</body>`, указав адрес вашего сервера:

```html
<script src="/translate.js"></script>
<script>
  translate.service.use('translate.service');
  translate.request.setHost('https://your-server.example/');
  translate.execute();
</script>
```

**3. Откройте свою страницу.** Появляется меню языков, и выбор языка переводит страницу на месте. Чтобы выбрать язык из своего кода, вызовите `translate.changeLanguage('japanese')`.

### Проверьте, работает ли всё

```
curl http://127.0.0.1:18097/health
curl -X POST http://127.0.0.1:18097/translate.json \
  -d 'from=english&to=japanese&text=%5B%22Hello%20world%22%5D'
```

Первая команда сообщает используемую модель. Вторая возвращает перевод в поле `"text"`, например, `["こんにちは世界"]`.

## Что защищает

Каждый перевод проверяется перед тем, как посетитель увидит его:

- Ссылки, адреса электронной почты, код в обратных кавычках и заполнители, такие как `{name}` или `%s`, должны проходить без изменений.
- Названия продуктов в списке исключений (AIEN, Omega, Aien и другие) никогда не переводятся. Используйте `--keep-file`, чтобы указать свой собственный список.
- Перевод, который пустой или значительно длиннее оригинала, отбрасывается.

Если какая-либо проверка не пройдена, посетитель увидит исходный текст вместо повреждённого перевода.

## Как это работает

- translate.js отправляет текст страницы на `/translate.json`. Сервер отправляет его модели порциями, по одному запросу за раз, поскольку GPU может быть общим.
- Каждый перевод сохраняется (SQLite), поэтому один и тот же текст никогда не переводится дважды. Повторные посещения происходят мгновенно.
- translate.js разделяет веб-адреса по `//`. Сервер сохраняет эти части на месте, чтобы ссылки корректно восстанавливались.
- Если ответ модели для порции не может быть сопоставлен с входными данными, порция делится и повторяется, до единичных элементов.

## Параметры

```
--listen     address to serve on        (default 127.0.0.1:18097)
--engine     model server               (default http://127.0.0.1:18091)
--cache      saved translations         (default ~/.local/state/aien-translate/cache.sqlite)
--keep-file  names never translated, one per line
```

Конечные точки: `/translate.json`, `/language.json`, `/connectTest.json`, `/init.json` и `/health`. `/ip.json` (поиск местоположения) не предоставляется.

## Тесты

- `cargo test` запускает юнит-тесты, а также тесты конечной точки против имитационной модели (не требуется GPU).
- `demo/` содержит страницу, использующую настоящий translate.js. Запустите папку и выполните `python demo/check.py URL` (требуется Playwright), чтобы увидеть переведённую страницу.

## Ограничения

- Скорость зависит от GPU. В среде выполнения AIEN один пакет обрабатывается примерно за секунду, когда GPU свободен, и значительно дольше, когда другой процесс использует его.
- Это машинный перевод. Он подходит для чтения, но не проходил ручную проверку человеком.
